# Research

This directory contains sanitized research from a Dex2C recovery campaign:

- `methodology.md` — evidence and validation method.
- `findings/` — verified final counts, evidence classes, limitations.
- `reports/` — Phase IV–VII notes and the final closure summary.
- `source-transformation-model.md` — attributed Dex2C transformation facts.

The lab does not publish target APKs, recovered third-party application code,
embedded payloads, raw device logs, or target-specific campaign drivers.
