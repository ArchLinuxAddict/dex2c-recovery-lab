# Contributing

- Do not submit target APKs, proprietary DEX/native files, embedded payloads,
  recovered third-party code, device serials, or personal paths.
- Use self-created synthetic fixtures. Include source and metadata.
- Record the toolkit version/commit and exact commands for every example.
- Distinguish structural validity, behavioral reconstruction, partial
  reconstruction, native-only analysis, and exact recovery.
- Run `python scripts/validate_lab.py` and both examples before opening a PR.
- Do not make claims that the available evidence does not support.
